## 5. Blank Swatch Fix & UI Verification

- **Root Cause Identified**: LLM outputs frequently return color names (`"Sage Green"`, `"Copper"`), bare hexes (`"BF5700"`), or hexes with descriptions (`"Emerald Green (#043927)"`). Placing these strings directly into inline `style="background-color: ..."` produced invalid CSS, causing browsers to drop the property and leave swatches blank.
- **Remediation**:
  1. `resolveCssColor()` parses the string, extracting valid hexes via regex, mapping 25+ celebration color names to calibrated tokens, and providing safe fallback chips.
  2. `.color-swatch-chip` in `styles/main.css` renders a preview box alongside a formatted hex chip label (`#043927`), ensuring every color is visible, accessible, and legible.
